# Security Policy

## Supported versions

Madako is experimental software. Security fixes are provided for the latest published release only. Please upgrade to the latest version before reporting an issue that may already have been fixed.

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected vulnerability. Instead, use GitHub's private vulnerability reporting form:

[Report a vulnerability privately](https://github.com/kohei0128/madako/security/advisories/new)

Reports in English or Japanese are welcome. Include as much of the following as you can:

- A description of the vulnerability and its potential impact
- The affected Madako version and relevant environment details
- Steps to reproduce the issue or a minimal proof of concept
- Any known workarounds or mitigations

Do not include credentials, personal data, or proprietary data in the report.

The maintainer will use the private security advisory to investigate, discuss remediation, and coordinate disclosure with you. Please allow a reasonable amount of time for a fix before publishing details of the vulnerability.
